A high-performance, dark-themed **ELITE FIT** gym web application featuring interactive service cards, animated statistics counters, 3D tilt effects, trainer profiles, membership tier plans, booking forms, and smooth navigation.

---

## 🚀 Key Features & Modules

- 🏋️ **Interactive Services Showcase:** 6 core training programs (*Weight Training*, *Cardio & Endurance*, *CrossFit*, *Personal Training*, *Yoga & Flexibility*, *Body Transformation*) with 3D tilt hover animations.
- ⚡ **Animated Statistics Counters:** Real-time animated counters for active members (5,000+), expert trainers (50+), years experience (15+), and success rate (98%).
- 🥊 **Elite Trainers Roster:** Detailed trainer profiles featuring specialties, experience badges, and bios for Alex Kumar, Sarah Johnson, Rajesh Desai, and Maya Patel.
- 💳 **Membership Pricing Tiers:** 3 flexible membership plans (*Basic*, *Pro*, *VIP Unlimited*) with feature checklists and instant trial booking CTA buttons.
- 📅 **Session & Trial Booking Form:** Interactive booking interface for scheduling free gym trials and trainer sessions.
- 🎨 **Modern Dark Neon Design System:** Curated dark-themed palette (`#0a0e27`, `#ff3333` neon red, `#00d4ff` electric blue) with custom cursor and glassmorphism cards.

## 🛠️ Local Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AvishkarRanjane/Elite-Fit-.git
   cd Elite-Fit-
   ```

2. **Run locally:**
   - Open `index.html` directly in your browser, or start a local HTTP server:
   ```bash
   npx serve .
   ```
   - Access the platform at `http://localhost:3000`.
