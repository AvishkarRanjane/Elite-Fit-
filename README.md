Welcome to the **Elite Fit Gym** official repository! This project is a premium, high-energy landing page designed for world-class fitness centers.

🔗 **Live Demo:** [https://elite-fit-gym-nine.vercel.app](https://elite-fit-gym-nine.vercel.app)

---

## ✨ Features

- 🎨 **High-Energy Dark Theme:** Built with a stark palette (Near-Black, Electric Red, Hot Orange, Off-White).
- 🚀 **Smooth 3D Tilt Cards:** Interactive and engaging hover effects for services and trainers.
- 📱 **Fully Responsive:** Flawless experience across all device sizes.
- ✅ **Form Validation:** Client-side validation for the trial booking system to ensure data integrity.
- 🏋️‍♂️ **Dynamic Counters:** Scrolling triggers animated statistics.

## 🛠 Tech Stack

- **HTML5:** Semantic and accessible structure.
- **CSS3:** Custom properties, Flexbox, Grid, keyframe animations, and 3D transforms.
- **JavaScript (ES6):** Intersection Observers, DOM manipulation, custom cursor, and event handling.
- **Fonts:** [Oswald](https://fonts.google.com/specimen/Oswald) (Display) & [Inter](https://fonts.google.com/specimen/Inter) (Body).
